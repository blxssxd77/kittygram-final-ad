# TeamFinder

Платформа для поиска команды. Реализован вариант 1

## Как запустить

1. Скопировать `.env.example` в `.env`
2. Выполнить `docker compose up --build`
3. Открыть http://localhost:8000

Миграции и тестовые данные подгружаются при первом запуске

Админка: http://localhost:8000/admin/
